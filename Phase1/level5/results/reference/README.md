# Measured Phase 1 reference

Generated by `make all` then `make reference`. `summary.csv` and `report.md` derive only from the retained `runs/` simulator CSVs. `provenance.json` contains commands, source hashes and tools; `trace_manifest.json` contains input/bridge provenance. Regenerate inputs with the recorded generators.

`analysis/` uses the imported Level 1 analyser with 16-byte lines. `verification.json` records the separate correctness benches. Additional high-latency smoke-test logs remain in the generated build directory.

These measurements describe deterministic subsystem simulation, not real inference execution or physical DRAM. No Phase 2 result is included.
