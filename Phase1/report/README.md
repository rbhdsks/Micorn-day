The 16-page report follows design thinking, explains Levels 1-5, defines the evaluation formulas, interprets positive and negative results and includes a separate low-rank CDM research chapter. The proposed CDM cache connection is not an implemented RTL feature.

Regenerating the Word file requires python-docx and the committed PNG figures. Rendering was verified with the Codex bundled LibreOffice workflow. The published PDF is the rendered counterpart of the Word file. Core RTL reproduction does not depend on document-generation packages.
